# UI 改版：Cinema First 设计

> 2026-10-25 与作者逐轮确认。目标是把现有三栏工具型界面改成「整窗即舞台」的浮层布局，同时保证字幕常驻时不遮挡画面。

**目标：** 画面成为绝对主角；控件按需出现；字幕抽屉常驻时画面自动让出安全区；保留全部现有功能与快捷键。

---

## 1. 范围

### 做

- 单层舞台布局：视频铺满窗口，顶栏、素材轨、字幕抽屉、控制条均为浮层。
- 右侧字幕抽屉 + 画面安全区避让。
- 左侧素材轨：收起为封面列，悬停或 `Ctrl+L` 展开；内含「最近播放 / 全部素材」双标签。
- 播放中静止 2.5 秒自动隐藏顶栏、素材轨、底部控件；移动鼠标或按键恢复。
- 状态感知的单一转写主按钮。
- 深色 + 浅色两套主题重新调校。
- 新增 `media_files.last_played_at` 字段与幂等迁移。

### 不做

- 不改转写、翻译、词典、悬浮字幕窗的内部逻辑。
- 不改媒体扫描和导入流程。
- 不做抽屉宽度拖拽（v1 固定宽度）。
- 不做文件夹分组（已确认由「最近播放 / 全部素材」替代）。
- 不改设置面板的功能结构，仅在外观页新增一个开关。

## 2. 布局规格

所有尺寸以 CSS px 计，窗口缩放时保持不变；只有窗口宽度低于断点时按 §7 降级。

| 元素 | 规格 |
| --- | --- |
| 顶栏浮层 | 高 52px，透明渐变底；左侧「素材轨开关 + 标题/元信息」，右侧「主按钮 + ⋯ + 窗口控制」 |
| 素材轨（收起） | 宽 44px，垂直封面列 + 底部设置按钮 |
| 素材轨（展开） | 宽 260px，玻璃面板；悬停延迟 180ms 展开 |
| 字幕抽屉 | 宽 320px，距窗口右/上/下各 16px 的玻璃面板 |
| 底部控制 | 进度行 + 控制胶囊；胶囊高 52px；整体占位约 88px |
| 面板圆角 | 14px；胶囊与分段控件为全圆角 |
| 元素间距 | 统一 16px 外边距，8px 组内间距 |

### 安全区规则

- **抽屉收起**：视频元素 `inset: 0`，整窗铺满；顶栏与底部控件叠加在画面上，靠自动隐藏解决遮挡。
- **抽屉展开**：视频元素改为 `top:16px; left:16px; right:336px; bottom:88px`，等比 `object-fit: contain`，四周留出环境底；底部进度与控制胶囊同步限制在 `right:336px` 内。
- 视频外的环境底使用深色径向渐变，不复制视频画面（避免双视频同步问题）。
- 过渡统一 320ms `cubic-bezier(.22,.61,.36,1)`；窗口尺寸变化时不做动画。

## 3. 交互规格

### 3.1 顶栏

- 最左按钮 = 素材轨开关，等价于 `Ctrl+L`。图标使用列表图标，不用汉堡图标。
- 标题区显示文件名与元信息：`TED · 6:35 · 精听 · 12 段字幕`；元信息缺失时逐项省略。
- 顶栏空白处设置 `data-tauri-drag-region`；按钮区域不参与拖拽。
- 窗口控制保留现有最小化/最大化/关闭逻辑，移到顶栏最右。
- 主按钮状态机：

| 状态 | 按钮文案 | 点击行为 |
| --- | --- | --- |
| 无文件 | 转写并翻译（禁用） | — |
| 无字幕 | 转写并翻译 | 启动全新转写（含自动翻译阶段） |
| `error` | 重新转写 | 全新转写，不续传 |
| `partial` | 继续转写 | 从断点续传 |
| `transcribing` / `translating` | 进度环 + 百分比 | 点击弹出「取消转写」 |
| 有原文、存在空译文 | 翻译 | 补齐空译文 |
| 有原文且全部有译文 | 已就绪 | 展开字幕抽屉（已展开则无操作） |

- `⋯` 菜单：导入字幕、重新翻译、悬浮字幕窗、画面比例、播放模式、设置、快捷键。

### 3.2 素材轨

- 收起状态显示 3–5 个最近封面，当前播放项高亮描边。
- 悬停 180ms 后展开；鼠标离开后延迟 180ms 收起。`Ctrl+L` 切换「固定展开」，固定状态只影响悬停行为，不阻止自动隐藏。
- 展开后顶部为双标签：
  - **最近播放**：按 `last_played_at DESC` 排序，只显示播放过的素材；空时提示「还没有播放记录」。
  - **全部素材**：保留现有搜索与四种排序（导入时间、标题、时长、字幕数）。
- 列表项：封面/占位、标题、时长、字幕标记、已播放进度细线。
- 导入文件、导入文件夹按钮放在展开面板工具区。
- 右键菜单、删除确认弹窗、悬浮详情全部保留，仅重做样式。

### 3.3 字幕抽屉

- 头部：标题「字幕」、`原文/双语/译文` 分段、搜索按钮、收起按钮。
- 搜索点击后在头部下方展开输入框，再次点击或清空后收起。
- 当前句卡片：原文、译文、`重听 / 下一句 / 锁定`。
- 文稿列表：时间戳 + 原文 + 译文；当前行高亮并自动滚动；点击跳转；右键查词。
- 空状态：无字幕时显示说明与「开始转写」按钮；转写中显示进度与取消。
- 展开/收起状态持久化到 `asplayer-subtitle-drawer-v1`（`open` / `closed`）。
  - 键不存在时按播放模式决定：精听 = 展开，连播 = 收起。
  - 用户手动切换后写入明确值，之后不再被模式切换覆盖。

### 3.4 自动隐藏

- 触发条件：正在播放、未暂停、无菜单/弹窗打开、鼠标在窗口内静止 2.5 秒。
- 隐藏范围：顶栏、素材轨、底部进度与胶囊。**字幕抽屉不隐藏**，它是内容而非 chrome。
- 恢复条件：鼠标移动、任意按键、窗口重新获得焦点、播放暂停。
- 全屏与窗口模式行为一致。
- 提供设置项「播放时自动隐藏控件」，默认开启，持久化键 `asplayer-chrome-autohide-v1`。

### 3.5 快捷键

- 复用现有绑定：`Ctrl+L` 素材轨、`Ctrl+T` 字幕抽屉、`Ctrl+,` 设置、`Space` 播放/暂停、`Esc` 关闭浮层。
- `Esc` 优先级：先关菜单/搜索，再收抽屉，最后退出全屏。

## 4. 视觉系统

### 4.1 结构层

三层，不叠加多余边框：

1. **环境底**：近黑或浅灰的纯色 + 轻微径向光。
2. **玻璃浮层**：半透明面板 + 24px 背景模糊 + 1px 内描边。
3. **内容层**：文字、封面、控件。

### 4.2 令牌

替换 `app/src/styles/tokens.css`：

| 令牌 | 深色 | 浅色 |
| --- | --- | --- |
| `--bg-0` 环境底 | `#08090a` | `#eef0f3` |
| `--bg-1` 面板底 | `#0e1012` | `#f7f8fa` |
| `--bg-2` 控件底 | `#16191c` | `#ffffff` |
| `--panel-bg` | `rgba(16,19,22,.72)` | `rgba(255,255,255,.82)` |
| `--panel-border` | `rgba(255,255,255,.09)` | `rgba(0,0,0,.08)` |
| `--fg-1` | `#f5f6f7` | `#17191c` |
| `--fg-2` | `#a8b0b8` | `#5c6268` |
| `--fg-3` | `#6b7178` | `#9299a0` |
| `--accent` | `#dfe9f2` | `#1c2024` |
| `--accent-soft` | `#a9c8ff` | `#3b6ea5` |
| `--on-accent` | `#0a1118` | `#ffffff` |
| `--danger` | `#e5484d` | `#d13438` |
| `--shadow-panel` | `0 24px 64px rgba(0,0,0,.45)` | `0 18px 48px rgba(20,24,30,.16)` |

- 主按钮、进度填充用 `--accent`；当前句锚点、选中描边用 `--accent-soft`。
- 危险操作只允许使用 `--danger`。

### 4.3 字体

- 字体栈：`"Segoe UI Variable Text", "Segoe UI", "HarmonyOS Sans SC", "MiSans", system-ui, sans-serif`。
- 标题 15px/600，元信息 12px，正文 13px，字幕原文 15px/1.5，译文 13.5px/1.5。
- 所有时间、进度、百分比使用 `font-variant-numeric: tabular-nums`。

### 4.4 动效

- 面板滑入/安全区变化：320ms `cubic-bezier(.22,.61,.36,1)`。
- chrome 淡入淡出：320ms ease。
- 悬停反馈：150ms ease。
- `prefers-reduced-motion: reduce` 下取消位移与淡出，只保留即时显隐。

## 5. 数据与迁移

### 5.1 字段

- `media_files.last_played_at TEXT NULL`。
- `MediaItem`（Rust + 前端类型）新增 `last_played_at: Option<String>`。
- `list_media` 的 SELECT 补该列。

### 5.2 写入

- `db.rs::save_playback_position` 改为：
  `UPDATE media_files SET playback_position = ?1, last_played_at = datetime('now') WHERE id = ?2`
- 现有前端每 3 秒保存一次进度，因此实际播放超过约 3 秒即产生记录；打开后立即关闭不会污染「最近播放」。

### 5.3 迁移

- 沿用 `db.rs` 现有的 `PRAGMA table_info` 幂等模式，新增 `migrate_last_played`，在 `init` 中调用：
  ```sql
  ALTER TABLE media_files ADD COLUMN last_played_at TEXT;
  ```
- 不新增索引：当前媒体库规模下由前端排序即可。

### 5.4 排序

- 最近播放：前端过滤 `last_played_at != null`，按字符串时间倒序（SQLite `datetime('now')` 格式可直接比较）。
- 全部素材：现有排序不变。

## 7. 边界与降级

- **窗口宽度 < 900px**：抽屉宽 280px，安全区右边距改为 296px。
- **窗口宽度 < 720px**：抽屉改为覆盖模式，禁用安全区，视频保持铺满；抽屉不透明度提到 92%。
- **无文件**：舞台中央显示「导入文件 / 导入文件夹」，顶栏保留，主按钮禁用，素材轨显示空库提示。
- **无字幕**：抽屉显示空状态；主按钮引导转写。
- **转写中**：主按钮显示进度环；素材轨与列表的「字」标记不闪烁。
- **全屏**：浮层与自动隐藏照常；抽屉展开时安全区生效。
- **浅色主题**：视频区域仍保持深色环境底，避免白底泛光；只有 UI 浮层变浅。

## 8. 测试与验收

### 自动测试

- `cargo test`：新增迁移幂等测试；`save_playback_position` 后 `last_played_at` 非空；旧库升级后字段存在。
- `npm run build`（或现有前端检查命令）：类型检查通过。

### 手动验收清单

1. 导入视频并播放：控件 2.5 秒后淡出，只剩画面与字幕；移动鼠标恢复。
2. 暂停时控件常驻。
3. 展开字幕抽屉：画面缩进左侧安全区，底部控件同步让位；无任何内容被遮挡。
4. 收起抽屉：画面恢复铺满，过渡无跳变。
5. 精听模式默认展开抽屉；连播模式默认收起；手动切换后重启仍保持手动选择。
6. `Ctrl+L` 展开素材轨；双标签切换；最近播放只显示播放过的素材，顺序正确。
7. 主按钮在六种状态下文案与行为正确。
8. 空库、无字幕、转写中、转写失败四种状态显示正常。
9. 浅色主题下所有浮层、文字、按钮对比度可读。
10. 720px 与 900px 断点行为正确。
11. 悬浮字幕窗、词典、设置、快捷键无回归。

## 10. 风险

- **布局重构面大**：`App.vue` 与 `PlayerStage.vue` 改动集中，需分步提交，保持每一步可运行。
- **安全区与全屏交互**：全屏下缩放视频可能导致黑边变化，需手动验证不同宽高比。
- **浅色主题**：玻璃与阴影在浅色下容易显脏，验收时以对比度和层次为准。
- **自动隐藏误触**：输入框聚焦、菜单展开、拖拽进度条时必须暂停计时器。
